# FS_2026.2_PO Repositorio para apresentacao do projeto fabrica 2026.2  
Em casos de violência doméstica, o tempo entre o pedido de socorro e a chegada da polícia é o que define quem sobrevive. 
Hoje eu apresento a vocês o Sistema Tamara. Ele não é apenas um software, é uma linha de vida. Criado em memória às vítimas que o Estado não conseguiu alcançar a tempo, este projeto é um ecossistema de resposta rápida e silenciosa.  O objetivo é simples, mas crítico: conectar uma mulher em perigo iminente, que já possui medida protetiva, diretamente à viatura mais próxima, otimizando o despacho do CIOP em segundos. É tecnologia aplicada à preservação da vida, desenhada com o rigor que a Polícia Militar da Paraíba exige.
